# Security Policy

## Supported Versions

Radiozaur to mały, jednoosobowy projekt — wsparcie dostaje tylko najnowsza wersja.

| Version | Supported          |
| ------- | ------------------ |
| 1.4.x   | :white_check_mark: |
| < 1.4   | :x:                |

## Reporting a Vulnerability

Znalezione luki bezpieczeństwa zgłaszaj przez [GitHub Issues](https://github.com/Maciej-EriAmo/Radiozaur/issues) w tym repozytorium.
